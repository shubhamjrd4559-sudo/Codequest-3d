# 📚 CodeQuest 3D Documentation Index

Welcome to the central technical documentation library for **CodeQuest 3D**. This directory contains detailed guides, architectural specifications, database schema diagrams, setup instructions, and development standards for contributors, maintainers, and reviewers.

---

## 🧭 Documentation Navigator

| Document | Primary Audience | Description |
|---|---|---|
| **[System Architecture (`ARCHITECTURE.md`)](./ARCHITECTURE.md)** | Architects & Engineers | High-level system design, frontend/backend communication, JWT token lifecycle, security boundaries, and database entity relationships. |
| **[Feature Catalog (`FEATURES.md`)](./FEATURES.md)** | Product Managers & Reviewers | Detailed breakdown of all implemented and planned platform features, including the 3D Arcade, Daily Quiz, Heatmap, and Leaderboard. |
| **[Local Setup & Troubleshooting (`SETUP.md`)](./SETUP.md)** | Developers & Contributors | Comprehensive environment setup instructions for Windows, macOS, and Linux, covering database seeding, virtual environments, and common fixes. |
| **[Developer Guide (`DEVELOPMENT.md`)](./DEVELOPMENT.md)** | Active Contributors | Code style conventions, TypeScript standards, ESLint configuration, Git branching flow, and pull request requirements. |
| **[Project Structure (`PROJECT_STRUCTURE.md`)](./PROJECT_STRUCTURE.md)** | All Developers | Exhaustive file and directory tree reference with responsibilities for every major module, route, and component. |
| **[Development Roadmap (`ROADMAP.md`)](./ROADMAP.md)** | Maintainers & Community | Strategic release milestones, chronological development history (Phases 1 through 10.1), and future architectural horizons. |
| **[REST API Reference (`api/endpoints.md`)](./api/endpoints.md)** | Frontend & Backend Engineers | Full specification of all v1 REST API endpoints with request bodies, response models, query parameters, and error codes. |
| **[Database Models Reference (`api/models.md`)](./api/models.md)** | Backend & DB Architects | Model relationships, field definitions, indices, and database constraints. |
| **[Master Project Vision (`PROJECT_IDEA.md`)](./PROJECT_IDEA.md)** | Project Visionaries | The original master design prompt, curriculum topics, and foundational pedagogical concepts. |
